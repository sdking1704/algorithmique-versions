Politique de confidentialité

Application ALGORITHMIQUE · éditeur : Dr ADS · en vigueur le 21 novembre 2026

ALGORITHMIQUE est une application pour apprendre l'algorithmique : on y écrit du pseudo-code, on l'exécute et on le comprend. Cette page explique, simplement, ce que l'application fait de vos informations. En résumé : l'éditeur ne collecte aucune donnée personnelle.

Ce qui reste sur votre ordinateur

  • Vos algorithmes sont enregistrés uniquement là où vous choisissez de les enregistrer. Ils ne sont jamais envoyés à l'éditeur ni à personne d'autre.
  • Vos réglages (thème, polices, voix…) et le brouillon en cours sont conservés sur votre ordinateur, dans le dossier de l'application.
  • Le nom que vous pouvez saisir pour l'export PDF sert uniquement à l'écrire dans le PDF et à vous le reproposer la fois suivante. Il reste sur votre ordinateur.
  • La lecture à voix haute utilise les voix installées dans Windows ou macOS, sur votre ordinateur.

Ce que l'application ne fait pas

  • Pas de compte à créer, pas de publicité, pas de mesure d'audience, pas de traceur.
  • Aucune donnée n'est vendue, louée ou partagée.

Achats, abonnement et dons

Dans la version installée depuis le Microsoft Store, l'abonnement Premium et les dons sont entièrement gérés par Microsoft, avec votre compte Microsoft. L'éditeur ne reçoit jamais vos coordonnées bancaires ni votre adresse e-mail : il reçoit seulement de Microsoft des rapports de ventes globaux. Pour savoir comment Microsoft traite ces informations, consultez la déclaration de confidentialité de Microsoft. Pour vérifier si votre abonnement est actif, l'application interroge le Microsoft Store sur votre ordinateur.

Mises à jour

La version du Microsoft Store est mise à jour par le Store. La version téléchargée depuis le site de l'application vérifie au démarrage si une nouvelle version existe, en lisant un fichier hébergé sur GitHub : comme pour toute page web, GitHub voit alors l'adresse IP de l'ordinateur (voir la déclaration de confidentialité de GitHub). Aucune autre information n'est envoyée.

Élèves et étudiants

L'application peut être utilisée par des élèves et étudiants, y compris mineurs : comme elle ne collecte aucune donnée personnelle, aucune information les concernant n'est recueillie par l'éditeur.

Supprimer vos données

Désinstaller l'application (Paramètres de Windows › Applications) supprime ses réglages et son brouillon. Vos fichiers .algo et vos PDF restent là où vous les avez enregistrés, et vous pouvez les supprimer vous-même.

Modifications et contact

Si cette politique change, la nouvelle version sera publiée sur cette page avec sa date. Pour toute question : page de contact de l'application.
